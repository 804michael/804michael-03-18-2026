What This Page Is

Every piece of this site that depends on something outside the repo — an API key, a Cloudflare binding, a third-party account — plus a live check on each one that can be checked from the browser. When something on the site quietly stops working, the cause is almost always one of the rows below.

Most failures here are silent by design. The site's server functions fall back rather than break: no ORS_API_KEY and the Tour Planner quietly switches to straight-line estimates; no KV binding and saved tours drop to one browser only. That's good for visitors and bad for noticing, which is what this page is for.

Run from your browser against this site's own /api/ endpoints. A red row means the thing genuinely isn't working; an amber row means it responded but is running on a fallback rather than the real service.

Accounts & Services

The full inventory, including the ones that can't be probed from here because they run entirely in the visitor's browser or on someone else's schedule.

1

Cloudflare

Hosts and deploys the whole site (Pages project, git-connected), serves every /api/ function, and holds the KV namespace behind saved tours, the dev hub's card order, notes and card edits, and the short-link redirector. Deploys run when you run push-live.bat. Where: Workers & Pages → the 804re.com project. KV namespaces live under their own "Workers KV" item, not nested under Workers & Pages.

2

EmailJS

Every lead form on the site. Called straight from the page, no server function involved, so it can't be checked from here — a broken template only shows up when a real visitor submits. Templates in use: template_valuation_request (Home Value + the index popup). Still not created: template_buyer_intake, template_seller_intake, template_contact_message — until each exists, that form shows a "please call or text instead" error rather than silently losing the lead. Where: dashboard.emailjs.com → Email Templates.

3

OpenRouteService / HeiGIT

Real driving order and route geometry for the Tour Planner. Free tier covers both the Optimization and Directions calls at this volume. The API moved to api.heigit.org — the old api.openrouteservice.org domain shut down. Where: the key is ORS_API_KEY in Workers & Pages → Settings → Environment variables; the account itself is at account.heigit.org.

4

FRED (St. Louis Fed)

Live mortgage-rate figures. Falls back to a hardcoded recent rate if the key is missing, so a stale rate on the site is the symptom. Where: FRED_API_KEY in the same Environment variables screen.

5

Google Sheets + Apps Script

The farm-stand map. New submissions land in the Sheet with Approved = FALSE and only appear on the public map once you flip that cell. The page reads the Sheet's "publish to web" CSV, which has its own cache delay of several minutes, so a new row won't show up instantly. The Apps Script (addstand.gs) geocodes addresses and emails you when one fails. Where: script.google.com, plus the Sheet itself.

6

Nominatim (OpenStreetMap)

Address autocomplete and geocoding on the Tour Planner and the valuation forms. Free, no key, no account — but it is a shared public service with usage limits, so heavy automated use would get rate-limited. Nothing to configure.

7

Short links

Now self-hosted: /api/shorten-link writes a code into the same KV namespace and /s/<code> redirects. No third party in the path. ElkQR and Replug accounts still exist and remain an option if a shorter branded domain (804re.link) is ever wanted on top of this.

8

CDNs

Leaflet (maps) from cdnjs, the EmailJS SDK from unpkg, QR images from api.qrserver.com, Google Fonts for Barlow. All keyless. If a map or a QR code fails to render and everything else on the page works, suspect one of these rather than anything of ours.

Cloudflare Keys & Bindings

The complete list of what has to exist in the Cloudflare dashboard for the site to run at full capability. A new key or binding only takes effect on a new deployment — either push a commit, or use Deployments → ⋯ → Retry deployment.

  • ORS_API_KEY — environment variable, encrypted. Powers route optimization and driving directions in the Tour Planner.
  • FRED_API_KEY — environment variable. Powers live mortgage rates.
  • TOURS_KV — KV namespace binding. Saved tours, and the short-link store.
  • DEV_ORDER_KV — KV namespace binding. The dev hub's card order, its notes, and card edits — all three share this one binding.

None of the /api/ endpoints require authentication. That's a deliberate call: they hold no lead data or personal information, only internal labels and route stops, and the pages using them are unlinked and noindexed. If any of them ever starts holding client information, add a shared-secret check before trusting a request body.
