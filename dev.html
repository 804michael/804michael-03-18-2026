Buyer Broker Agreement e-signature generator (Buyer Intake Form)

Michael's idea: auto-generate and send the Buyer Broker Agreement for e-signature from buyer-intake.html, using Signaturely, FlexiSign, or Authentisign. Research so far — Signaturely: has a REST API, but full API access needs a paid tier (Gold $49/mo up to Titanium $199/mo); general-purpose template library, no real-estate-specific template confirmed, free API test available before committing. FlexiSign: plans run $5–49+/mo, but the pricing page doesn't disclose API access/cost directly — a Pipedream integration confirms an API exists, but auth method and full capabilities still need confirming directly with FlexiSign. Authentisign (Lone Wolf/Instanet): real-estate-specific ("real estate's leading eSignature solution"), documented API at apidocs.lwolf.com covering signing sessions, documents, participants, workflow, and layouts — but public access eligibility and pricing aren't disclosed; likely requires an existing Lone Wolf/Instanet account or direct contact with them. Not yet confirmed whether Michael already has an Authentisign account (commonly bundled with MLS/transaction-management tools). Needs a provider decision + confirmed API access/pricing before building. Added 2026-09-04
